# APK signing (AOSP testkey)

`aosp-testkey.p12` is the public Android Open Source Project **testkey**
(`CN=Android`, SHA-1 `61ed377e85d386a8dfee6b864bd85b0bfaa5af81`).

Head units that accept the gallery package rename expect this certificate.
Password / alias: `android` / `androidtestkey`.

Do not use this keystore for Play Store or any trusted distribution.
