# 兼容性

**简体中文** | [English](#compatibility-english)

## 支持范围

| 项 | 状态 |
| --- | --- |
| 车机品牌 | **仅零跑 Leapmotor** |
| 其它品牌 | 可能碰巧运行，**不支持**、不计划修品牌问题 |
| Android | 7.0+（API 24+）；7.0–8.1 实车验证不完整 |
| iPhone / iOS | 支持系统 CarPlay 的机型；随 iOS 变更，兼容性不保证永久 |

## 明确不做的承诺

- 非 Apple 认证产品；不保证所有车机 / 所有 iOS 版本
- 不保证消灭全部卡顿、掉线、Siri / 通话、解码器问题
- 实验性设置默认关闭；打开前请停车测试
- 配件身份为实验性公开提取物，可被再提取；未来接受度未知

## 连接后端差异（摘要）

| 后端 | 注意 |
| --- | --- |
| 车机热点 | 凭据必须精确；自动加入依赖固件 / 蓝牙握手 |
| USB | 数据口 + 数据线；充电策略可影响稳定性 |
| Wi-Fi Direct | 7–9 频率未验证；10+ 可校验；固件 API 缺失则不可用 |
| 同一局域网 | 依赖外部路由；应用不改路由 |

## 零跑集成

风挡导航、仪表卡片、氛围灯、来电弹窗等依赖具体 Leapmotor OS / 固件版本。未验证的路径不会写成「已支持」。细节见 [导航与仪表](导航与仪表.md)。

# Compatibility (English)

[简体中文](#兼容性) | **English**

**Leapmotor only.** Android 7.0+ with incomplete vehicle proof for 7.0–8.1. Not Apple-certified. Experimental options are opt-in. Wi-Fi Direct on Android 7–9 cannot verify negotiated frequency. Vehicle integrations depend on exact Leapmotor firmware; unverified paths are not claimed as supported.
