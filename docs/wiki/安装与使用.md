# 安装与使用

**简体中文** | [English](#installation-and-usage-english)

本文是 TuPigCarPlay 的完整安装与日常使用说明。只想「装上就能连」看前三节即可。

> [!IMPORTANT]
> - 安装目标是 **零跑 Leapmotor 车机**，不是 iPhone。
> - 下载请只用本仓库 [Releases](https://github.com/Tupig/TuPigPlay/releases)。
> - 公开预览版，**未经 Apple 认证**；详见 [第三方声明](../THIRD_PARTY_NOTICES.md)。

## 1. 下载

| 项 | 说明 |
| --- | --- |
| 产物 | `TuPigCarPlay-*.apk`（主应用，模块 `mobile`） |
| 渠道 | [GitHub Releases](https://github.com/Tupig/TuPigPlay/releases) |
| 系统 | Android 7.0+（API 24+）；7.0–8.1 实车验证仍不完整 |

原地升级请使用**同一包名、同一签名**的 APK，以保留设置与配对记录。不要凭文件名推断签名兼容性。

## 2. 安装

1. 停车后，在车机上允许「未知来源」或厂商提供的 APK 安装方式。
2. 安装 APK；**不要**装到 iPhone。
3. 打开 TuPigCarPlay，按你要用的功能授权：
   - 蓝牙 / 附近的设备：发现与配对
   - 定位（部分旧系统）：Wi-Fi 相关
   - 麦克风：Siri / 通话
   - 通知：连接控制相关提示
4. 连接前关掉其它手机投屏 / CarPlay 类应用。

也可用已授权的 ADB（可选，非核心必需）：

```sh
adb install -r TuPigCarPlay-*.apk
```

## 3. 第一次连接

1. 打开 **设置 → 连接 → 连接方式**。
2. 推荐：**车机自带热点**（尽量 5 GHz），填写与车机完全一致的热点名称与密码并保存。
3. iPhone 打开蓝牙与 Wi-Fi，与车机蓝牙配对。
4. 回到主界面点 **连接手机**。
5. 有线则：用支持数据的线插到车机 **数据口**，选 USB 连接，并同意信任 / USB / 本地 VPN 提示（本地 VPN 只承载 USB 链路，不是上网 VPN）。

详细四种连接见 [连接方式](连接方式.md)。

## 4. 更新

- 应用约每天检查一次本仓库公开 Release；主页可出现 **有可用更新**。
- **关于** 中可手动下载；需你点确认后才会安装。可在关于里关闭后台检查。
- 校验发布校验和后再安装。

## 5. 诊断报告（报 Issue 前）

1. 在当前版本上复现问题，记下大概时间。开机 / 自启问题可复现后再手动打开应用导出。
2. **设置 → 诊断 → 保存诊断报告**。Android 10+ 通常到 **Downloads/TuPigCarPlay**；更旧系统会要存储权限。
3. 用确认框里的 **查看 / 分享**；审阅 `.txt`，删掉热点密码等隐私后再贴到 [Issues](https://github.com/Tupig/TuPigPlay/issues)。
4. 请写明：车型 / 车机、Leapmotor OS / Android / 完整固件、iPhone / iOS、连接方式（USB / 车机热点 / Wi-Fi Direct / 同一局域网）、相关设置、复现步骤、预期与实际、故障时间。

报告**不会**自动上传。政策见 [隐私政策](../PRIVACY.md)。

## 6. 语言

应用内可选多种语言（含简体中文、繁体中文台湾、意大利语、日语等）。Android 13+ 与系统「按应用设置语言」同步。香港 / 澳门 / Hant 选择使用台湾译文，不单独宣称地区版。

# Installation and usage (English)

[简体中文](#安装与使用) | **English**

Install **TuPigCarPlay** on a **Leapmotor** Android head unit from [Releases](https://github.com/Tupig/TuPigPlay/releases). Do not install on the iPhone.

1. Allow APK installs; grant Bluetooth/Nearby, location (older Android), microphone, notifications as needed.
2. Close other projection apps.
3. Prefer **built-in car hotspot** (5 GHz) under **Settings → Connection → Connection setup**, or USB / Wi-Fi Direct / Same LAN — see [连接方式](连接方式.md).
4. For bugs: reproduce on the current build, **Settings → Diagnostics → Save diagnostic report**, redact secrets, attach to an [Issue](https://github.com/Tupig/TuPigPlay/issues) with vehicle/firmware/iPhone/backend details.

Optional: `adb install -r TuPigCarPlay-*.apk`. Not Apple-certified; see [THIRD_PARTY_NOTICES](../THIRD_PARTY_NOTICES.md).
