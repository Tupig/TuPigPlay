# 连接方式

**简体中文** | [English](#connection-backends-english)

在 **设置 → 连接 → 连接方式** 中选择一种后端。核心 CarPlay **不需要 ADB**；部分零跑车辆数据 / 自动控制需要已授权的网络 ADB 与支持的固件。

## 1. 车机自带热点（默认推荐）

1. 打开车机热点，优先 **5 GHz**。
2. 在 TuPigCarPlay 填入与车机**完全一致**的名称与密码并保存。
3. iPhone 保持蓝牙 + Wi-Fi，并与车机蓝牙配对。
4. 点 **连接手机**。部分固件可通过蓝牙握手下发热点凭据；若未自动加入，可手动连上热点后再看 CarPlay 是否起来。

可选：**设置 → 连接** 下的「自动开车机热点」默认关闭；在支持的固件上通过已授权 ADB 操作本应用自己的权限，不会替你改热点名密码。详见下文「可选 ADB」。

> [!NOTE]
> 旧的「本机热点」选项已移除，会迁移到车机自带热点。

## 2. USB 有线

1. 使用支持**数据**的线，接到车机 **USB 数据口**（纯充电口无效）。
2. 选择 **用 USB 连接**，批准 USB 访问、信任 / CarPlay、以及本地 VPN（仅 USB 网络，不是上网 VPN）。
3. 若每隔几秒掉线且 iPhone 自己重连：可试 **设置 → 连接 → USB 连接 → iPhone 充电 → 降低 / 低**（充电会变慢）。

## 3. Wi-Fi Direct

适用于 Android 7.0+ 且固件实现了所需 API 的车机。

| 系统 | 行为要点 |
| --- | --- |
| Android 7.0–9 | 走旧版建组路径，使用系统返回的真实凭据；**无法校验协商频率**，诊断里请求信道可能标为未验证 |
| Android 10+ | 保留频率校验 |

**首选信道**（设置里）：Auto 为默认；也可锁定 2.4 / 5 GHz 或具体信道。保存作用于**下一次**连接；被电台拒绝或建到其它信道时请改回 Auto 或换信道。信道选择**不能**单独证明卡顿已修好。

残留旧组时：**设置 → 连接 → 无线连接帮助 → 重置 CarPlay Wi-Fi**（删除未知组前会询问）。优先原地升级，少卸载。

## 4. 同一局域网（Existing Wi-Fi / Same LAN）

车机与 iPhone 都连到同一外部路由 / 随身 Wi-Fi：

1. 关闭路由器客户端隔离。
2. 在连接方式中保存该网络。
3. 保持蓝牙开启。

TuPigCarPlay **不会**替你连网或改默认路由。

## 5. 可选：ADB 相关能力

| 能力 | 说明 |
| --- | --- |
| 自动开车机热点 | 默认关；需可达且已授权的 ADB，以及固件提供的开热点命令 |
| 车辆数据 / 仪表 / 部分导航卡片 | 见 [导航与仪表](导航与仪表.md)；默认 DiLink 5.0 路径，旧机只读探测需显式打开 |

未授权 ADB 时，核心有线 / 无线 CarPlay 仍应可用。

## 6. 连接失败时

1. 看界面上的失败阶段文案。
2. 导出 [诊断报告](安装与使用.md#5-诊断报告报-issue-前)。
3. 对照 [常见问题](常见问题.md) 与 [无线排障](无线排障.md)。

# Connection backends (English)

[简体中文](#连接方式) | **English**

Backends under **Settings → Connection → Connection setup**:

1. **Built-in car hotspot** (default): save exact SSID/password; prefer 5 GHz; keep iPhone Bluetooth+Wi-Fi paired.
2. **USB**: data cable + data port; approve USB/Trust/local VPN (USB link only).
3. **Wi-Fi Direct**: Android 7–9 legacy groups without frequency verify; Android 10+ verifies. Preferred channel applies next connect.
4. **Same LAN**: car and iPhone on one external network; no client isolation; app does not change routes.

Core CarPlay needs no ADB. Optional hotspot automation and vehicle/cluster features need authorized network ADB on supported Leapmotor firmware.
