# 常见问题

**简体中文** | [English](#faq-english)

## 安装与更新

**Q：装到手机上了？**  
A：请装在零跑车机上。iPhone 只跑系统 CarPlay。

**Q：更新后设置丢了？**  
A：需同一包名与同一签名原地覆盖安装。换签名等于新应用。

**Q：桌面图标还是旧的？**  
A：部分车机会缓存启动器图标，清数据或重装后再看。

## 连接

**Q：点连接没反应 / 一直转？**  
A：确认连接方式与凭据；关掉其它投屏；看界面失败阶段；导出诊断报告。热点名称密码必须与车机完全一致。

**Q：USB 只充电不进 CarPlay？**  
A：换数据线 / 数据口；同意信任与 USB；可试降低 iPhone 充电档位。

**Q：Wi-Fi Direct 很卡？**  
A：信道与固件有关；可试 Auto、2.4/5 GHz 或车机热点 / 同一局域网。信道选项本身不保证消灭卡顿。见 [无线排障](无线排障.md)。

**Q：同一局域网连不上？**  
A：确认无客户端隔离；车机与 iPhone 同网段；应用不会改默认路由。

## 音频与 Siri

**Q：音乐慢半拍或忽快忽慢？**  
A：先升到当前 Release；仍有问题请带诊断报告开 Issue（注明有线/无线）。

**Q：通话 / Siri 没声或闪退？**  
A：检查麦克风权限；部分车机无系统 Opus 时走软件编码路径，请用当前版本复现后出报告。

## 显示

**Q：圆角露出壁纸？**  
A：CarPlay 内安全区 → 黑色圆角遮罩；或方形无安全区。

**Q：改分辨率没变化？**  
A：会话中需 **应用并重连**；仅点选不保存不会生效。

## 零跑功能

**Q：仪表 / 风挡导航没有？**  
A：需支持的 Leapmotor 固件；部分能力要已授权 ADB。见 [导航与仪表](导航与仪表.md)。

**Q：其它品牌车机能用吗？**  
A：不在支持范围，不承诺修品牌专属问题。

## 仍无法解决

按 [安装与使用 · 诊断报告](安装与使用.md#5-诊断报告报-issue-前) 收集信息后到 [Issues](https://github.com/Tupig/TuPigPlay/issues) 反馈。

# FAQ (English)

[简体中文](#常见问题) | **English**

Install on the **Leapmotor** head unit only. Match package + signing for upgrades. Hotspot SSID/password must match exactly. USB needs a data cable/port. Wi-Fi Direct channel tweaks do not guarantee smooth audio. Same LAN needs no client isolation; the app does not change routes. Scope is Leapmotor-only. Export a diagnostic report before filing an [Issue](https://github.com/Tupig/TuPigPlay/issues).
