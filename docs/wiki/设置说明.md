# 设置说明

**简体中文** | [English](#settings-guide-english)

设置按**驾驶目标**分组（不是按实现模块）。实验性项标题带 `（实验性）` / `(experimental)`。

> 改完若说明写「下次连接生效」，保存后会出现 **立即重连** 条；**不会**未经同意强断当前会话。需立刻生效且会重连的项，按钮文案为 **应用并重连**。

## 总览 Overview

连接状态、分类入口、少量快捷项、关于与语言。不要把新设置塞进总览；先放进对应分类，常用再升快捷项。

## 连接 Connection

- 连接方式（热点 / USB / Wi-Fi Direct / 同一局域网）
- 打开即连、随车启动、USB 权限、车机热点自动化、选择 iPhone、安卓权限
- 无线连接帮助（含重置 CarPlay Wi-Fi）

## 显示 Display

- 日夜模式、画面、尺寸、分辨率、帧率、程序坞、系统栏、多窗口分辨率
- **界面尺寸**：只影响 TuPigCarPlay 自己的控件，不影响 CarPlay 画面
- 建议起步：30 fps、默认图标文字；**高效视频 (HEVC)** 在高级里默认关
- 卡顿车机可试分辨率 80% / 60%；部分组合仍可能忽略图标文字缩放

CarPlay 内手势下滑打开快捷菜单（默认三指，可在 **车辆 → CarPlay 控制** 改为二/四指或关）。全屏时可选手势上滑 **临时显示系统栏（约 5 秒）**（默认关）。

圆角漏壁纸：**安全区 → 黑色圆角遮罩**（默认关）；另有实验性 iPhone mask，依赖下次连接协商。

## 音频 Audio

媒体 / 导航声道路由、音乐缓冲等。

## 导航 Navigation

位置上报、零跑风挡 / 仪表导航相关项。详见 [导航与仪表](导航与仪表.md)。

## 车辆 Vehicle

驾驶方位、方向盘按键（Siri、摇杆、地图缩放、可选播放/暂停键）、车机按键、与车机冲突的手势。

方向盘播放/暂停：默认关；在 **方向盘按键** 里学习空闲键。通话中或未连接时不接管。Fire TV / 标准 HID 媒体键不能改成播放暂停。部分 OEM 在应用收到前拦截按键，诊断里看不到则无法映射。

## 诊断 Diagnostics

保存 / 查看 / 分享诊断报告；可选 FPS 计数等。

## 高级 Advanced

实验性、固件相关或风险较高的项，例如：仪表地图、分屏、旋转、侧栏、HEVC、音频焦点、声道映射、缓冲音乐、车辆数据等。默认多为关闭。

# Settings guide (English)

[简体中文](#设置说明) | **English**

Settings are grouped by driver goal: **Connection**, **Display**, **Audio**, **Navigation**, **Vehicle**, **Diagnostics**, **Advanced**. Overview only holds status, category links, a few quick settings, About and language.

Items that apply at the next connection show **Reconnect now** after save; they do not drop the session without consent. Live reconnect uses **Apply and reconnect**. Experimental titles use the locale’s `(experimental)` / `（实验性）` suffix.
