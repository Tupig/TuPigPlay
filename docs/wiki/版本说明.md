# 版本说明

**简体中文** | [English](#release-notes-english)

公开预览版摘要。完整工程变更以 Git 历史与 [CHANGELOG.md](../../CHANGELOG.md) 为准。下载：[Releases](https://github.com/Tupig/TuPigPlay/releases)。

本仓产品版本从 **0.0.1** 起计。下文 `0.2.x` 为分叉前 DiPlay 预览要点，便于对照，**不是**本仓 tag。

> 旧的按版本英文长文 `RELEASE-NOTES-0.2.*.md` 已归档到 [`docs/archive/`](../archive/)（只读参考）。

## 0.0.1（2026-10-25）

- 产品号重置为 `0.0.1`（`versionCode` 1）；更新检查与发版资产走本仓 Releases。
- 面向零跑的文档与品牌整理；SemVer / 涨号 / 软更新约定见 [版本与更新](版本与更新.md)。

## 0.2.21（2026-10-17）

- 修正 0.2.20 音乐落后 / 变速问题；中断后音乐会恢复。
- 有线：iPhone 未打开会话时可自恢复；断开后不再死等；已恢复的连接不被误断开。
- 无系统 Opus 的车机上用麦克风不再因此闪退。
- 无线启动失败有原因文案；零跑上车结束后交还仪表；DiYou 桌面卡片打开更稳。
- 可装 Android 7.0；新增意大利语。
- 多项默认关闭的新选项（临时系统栏、黑色圆角、方向盘播放暂停、双击 Siri、导入热点、悬浮球、原厂音乐律动等）。

## 0.2.20

- 音频时钟漂移补偿、线程优先级、无线/USB 分缓冲。
- 通话外放、Siri 与车机语音键行为、有线启动若干时序修复。
- 车机热点开启路径（含非 ADB 场景能力边界）、Wi-Fi Direct 扫描暂停开关等。
- 仪表控制器与 HEVC→H.264 回退、设置菜单按目标分组。

## 0.2.19

- 有线更快启动、USB 权限与 Auto-confirm、通话采样率与麦克风恢复。
- 仪表地图触控/倒车后缩放、日语与繁中完善、诊断可用手机扫码拉取等。

## 0.2.18

- 有线会话读写竞态、Android 7.1 / USB 音频占用、无 VPN 对话框（已授权 ADB）等。
- 音乐包丢弃与反馈时钟、连接阶段多语言、方向盘与通话键、设置备份恢复。

## 0.2.13–0.2.17（合并摘要）

- Wi-Fi Direct Android 9 旧路径与信道、热点地址族、Auto 选信道策略。
- 繁体中文、缓冲音乐 / 侧栏等实验项、连接恢复与诊断增强。
- 音频欠载、麦克风 Opus 软件回退、无线流畅度相关修复（仍需实车证据）。
- 安装下限逐步覆盖更低 Android；意大利等语言；大量零跑桌面 / 仪表 / 通话弹窗相关修复。

## 0.2.9–0.2.12（合并摘要）

- 日夜跟随、音轨选择、环视窗口、乌克兰语、仪表歌曲卡、导航小组件、悬浮/嵌入地图与示例 launcher。
- 媒体会话封面、AirPlay 端口占用、Wi-Fi Direct / USBMUX 硬化、回声消除、电池 CAN/CANFD、P 挡可选视频。
- Wi-Fi Direct 首选信道、仪表转向卡、多指设置手势、旧车车辆数据探测、自动热点、TV 遥控。
- 大批集成期回归修复（USB 对话框范围、悬浮地图、设置取消、DiLink 路径、诊断导出回退路径等）。

## 下一版（NEXT）
