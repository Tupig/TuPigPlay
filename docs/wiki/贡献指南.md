# 贡献指南

**简体中文** | [English](#contributing-english)

感谢关注 TuPigCarPlay（仓库 [Tupig/TuPigPlay](https://github.com/Tupig/TuPigPlay)）。

## 原则

1. **支持范围是零跑 Leapmotor**；其它品牌兼容不作为目标。
2. 每个需求 / 疑问 / 缺陷尽量对应独立 GitHub Issue（见根目录 [AGENTS.md](../../AGENTS.md)）。
3. 分支名关联 Issue；PR 描述写 `Closes #编号`。
4. 设置项改动遵循 AGENTS.md 中的分类与翻译要求。

## 提 PR 前

```sh
./gradlew :shared:testDebugUnitTest :common:testDebugUnitTest :home:testDebugUnitTest \
  :mobile:lintDebug :home:lintDebug :maphost:lintDebug \
  :mobile:assembleDebug :home:assembleDebug :maphost:assembleDebug
```

## 安全

不要把密钥、配件私钥、热点密码写进 Issue 或提交。漏洞走 [SECURITY.md](../../SECURITY.md) 的私密渠道。

## 文档

用户文档在 `docs/wiki/`，风格对齐 TuPigGHD2Chinese：中文优先、同页 English、少流水账。
