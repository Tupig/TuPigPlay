# 导航与仪表

**简体中文** | [English](#navigation-and-cluster-english)

面向 **零跑 Leapmotor** 车机上的导航投送、仪表 / 风挡显示与相关实验项。未在你的固件上验证前，请当作「可能可用」。

## 位置与导航音频

- **设置 → 导航**：是否向 iPhone 上报位置、导航相关音频等。
- 首次引导里可能写入合理默认；可随时在设置中改。

## 仪表 / 风挡（固件相关）

| 能力 | 说明 |
| --- | --- |
| CarPlay 地图上仪表 | 高级 / 导航相关开关；仪表地图流是悬浮地图、嵌入地图等的前提 |
| 转向卡片 / 距离 / 路名 | 依赖已验证固件路径；未知机动不会编造直行箭头 |
| 主题跟随 | 部分固件在 CarPlay 前台时跟随车机日夜；可用 Usage Access 推断少数原厂仪表活动（可选、可关） |

Usage Access 仅本地处理有限活动名，不上传。详见隐私政策。

## 通话与仪表卡片（实验性，默认关）

独立实验项可能出现在导航或高级车辆数据下，例如仪表上来电相关能力。需要已授权 ADB 与目标固件；打开前请阅读当前 [版本说明](版本说明.md) 中的限制。

## 桌面与启动器

- 标准安卓导航小组件：需要支持小组件的启动器；零跑内置主页通常不接受任意小组件。
- 悬浮地图 / 嵌入地图：需开启仪表地图相关选项，并注意悬浮窗 / Usage Access 权限。

更多历史细节原分散在旧备忘中；以本页与设置内说明为准。

Leapmotor-specific HUD/cluster navigation, theme following, and optional call/map cards. Most paths are firmware-dependent; optional ADB features stay off by default. Widget/floating map need a capable launcher and cluster-map enabled.
