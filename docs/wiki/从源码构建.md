# 从源码构建

**简体中文** | [English](#build-from-source-english)

## 模块

| 模块 | 用途 |
| --- | --- |
| `mobile` | **主应用 APK**（日常构建选这个） |
| `home` | 主页 / 设置相关示例或配套 |
| `maphost` | 地图宿主演示，不是主产品 |
| `shared` / `common` | 库代码 |

产品版本在根目录 [`version.properties`](../../version.properties)（`VERSION_NAME` / `VERSION_CODE`）。发版与自动更新见 [版本与更新](版本与更新.md)。

## 环境

- JDK（与 CI / `local.properties` 中 Android SDK 一致）
- Android SDK；可用 `ANDROID_HOME` 或 `local.properties` 的 `sdk.dir`

## 常用命令

与 [AGENTS.md](../../AGENTS.md) / CI 一致的检查（改代码后建议跑）：

```sh
./gradlew :shared:testDebugUnitTest :common:testDebugUnitTest :home:testDebugUnitTest \
  :mobile:lintDebug :home:lintDebug :maphost:lintDebug \
  :mobile:assembleDebug :home:assembleDebug :maphost:assembleDebug
```

只打调试主包：

```sh
./gradlew :mobile:assembleDebug
```

## 签名与配件身份

- Git **不包含** Android 发布签名密钥与配件私钥。
- 普通源码 / CI 构建默认**不**打入运行时配件身份。
- 发布用 APK 若包含实验性身份，需在本地显式指定外部资源目录；APK 一旦分发，其中身份可被提取。详见 [SECURITY.md](../../SECURITY.md) 与 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。

`mobile/signing/` 仅说明本地签名布局，勿把密钥提交进库。

## Git 远程

本地若加了名叫 `upstream` 的远程指着 DiPlay 仓库，只用来拉对方更新，**不要**把本仓改动推过去。对外说明和零跑范围以本仓文档为准。
