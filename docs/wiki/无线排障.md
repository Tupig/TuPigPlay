# 无线排障

**简体中文** | [English](#wireless-troubleshooting-english)

## 先确认后端

| 现象 | 先查 |
| --- | --- |
| 车机热点 | SSID/密码是否与车机一致；是否 5 GHz；iPhone 是否已蓝牙配对；能否手动加入热点后进入 CarPlay |
| Wi-Fi Direct | 系统版本与固件 API；首选信道；是否有残留 P2P 组 |
| 同一局域网 | 同网、无隔离、蓝牙开 |

## 车机热点

1. 车机侧热点保持开启；应用内保存的凭据与车机 UI **逐字符一致**。
2. 若蓝牙握手不自动下发凭据：在 iPhone 手动连热点，看 CarPlay 是否仍能起来（区分「加不上网」与「AirPlay/会话失败」）。
3. 可选「自动开热点」失败：看诊断里 ADB / 权限 / 固件命令是否成功，以及是否观察到热点就绪。

## Wi-Fi Direct

1. **重置 CarPlay Wi-Fi**（设置 → 连接 → 无线连接帮助）清理未知组后再试。
2. 信道：Auto → 试 Auto·2.4 / Auto·5 → 再试具体信道；被拒绝就换，不要假设「锁信道 = 不卡」。
3. Android 7–9：诊断中频率/信道「未验证」是预期限制。
4. 仍卡顿：对比同环境车机热点或同一局域网，把对比结果写进 Issue。

## 流畅度相关设置（谨慎）

高级里的缓冲音乐、流畅视频、低延迟解码、直通输出等**默认关**。改动可能重连或牺牲画质/触控；逐项试并准备回退。

## 需要的证据

导出诊断报告，注明：后端、信道/频段、是否手动加过热点、大概卡顿时刻、其它投屏是否关闭。见 [安装与使用](安装与使用.md#5-诊断报告报-issue-前)。

# Wireless troubleshooting (English)

[简体中文](#无线排障) | **English**

Match hotspot credentials exactly. Separate “cannot join Wi-Fi” from “session fails after join”. Reset CarPlay Wi-Fi for stale P2P groups. Channel picks are troubleshooting knobs, not stutter guarantees. Android 7–9 cannot verify negotiated frequency. Compare backends and attach a diagnostic report when filing issues.
