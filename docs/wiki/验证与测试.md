# 验证与测试

**简体中文** | [English](#validation-and-testing-english)

## 自动化（每个改动）

在合并或宣称完成前，跑 CI 同款命令（见 [从源码构建](从源码构建.md)）：单元测试、lint、assembleDebug。

## 实车验证

- 范围：**零跑 Leapmotor** 车机 + 真实 iPhone。
- 记录：车型、Leapmotor OS / Android / 固件全文、iOS、连接后端、相关设置、通过/失败项。
- 未在实车跑过的能力，文档与 Release 中不得写成「已验证支持」。

## 诊断

用户侧导出流程见 [安装与使用](安装与使用.md#5-诊断报告报-issue-前)。开发者排查无线时结合 [无线排障](无线排障.md)。

## 历史验证备忘

旧的按日期 VALIDATION / HOTSPOT_JOIN_VALIDATION 等英文长文已收敛为本页原则；具体一次路测结果请写在对应 Issue 或 Release 说明，避免多份文档互相打架。
